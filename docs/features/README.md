# Features

- [Dashboard](DASHBOARD.md): overview, lifecycle totals, coverage and source navigation.
- [Role Lookup](ROLE_LOOKUP.md): catalogue, role relationships, transactions and existing Role Comparison.
- [User Access](USER_ACCESS.md): directory, profiles and assignment investigation.
- [Compare Users](COMPARE_USERS.md): shared/unique roles and role-derived transactions, with source intervals.
- [Account Review](ACCOUNT_REVIEW.md): evidence-based findings and persistent review decisions.
- [Release Roles](RELEASE_ROLES.md): PR/PO assignments, filters and distinct-user matrix.
- [Saved Filters](SAVED_FILTERS.md): reuse named investigations without storing result datasets.
- [Shared Filters](FILTERS.md): transaction operators, assignment dates and scoped clearing.

Sources are described in [Data & CSV](../data/README.md). Assignments, mapped
transactions, SAP validity/lock and AD status remain separate evidence; none alone
establishes effective authorization, recent usage or licensing entitlement.
